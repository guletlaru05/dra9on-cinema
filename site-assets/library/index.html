참고한 자료

관련 있는 내 튜토리얼을 먼저 보여줍니다. 원문 프롬프트는 요약 없이 펼쳐보고 복사할 수 있습니다.

저장한 프롬프트

모바일과 PC에서 같은 소유자 계정으로 열 수 있습니다. 최대 50개이며, 한도에 도달하면 기존 자료를 삭제한 뒤 저장하세요.

발견한 자료 한곳에

직접 고른 공개 링크만 넣으세요. 프롬프트 / 툴·플랫폼 / 사람 / 기타로 분류합니다. 로그인이 필요한 SNS 글은 읽지 못할 수 있습니다. 사람 자료에는 공개 활동만 남깁니다.

PC 자료실·MCP와 동기화

사이트에는 내 PC의 전체 데이터베이스를 올리지 않습니다. 대기 링크와 직접 저장한 프롬프트만 내보내 PC에서 처리합니다. PC를 사용할 수 있을 때 Codex가 처리하거나, 내보낸 파일을 로컬 동기화 도구에 전달하세요.

BEGINNER / SMALL SCENE FIRST

짧은 장면 하나를 완성해 보세요

인물 한 명이 방에서 인기척을 듣고 문을 돌아보는 과제로 시작합니다. 제작 지도 → 얼굴 → 시트 → 공간 → 행동 → 카메라 → 입력 → 검수 → 편집 순서입니다. 각 실습에 준비, 작업 과정, 확인 방법과 오류 해결을 넣었습니다.

PDF를 바탕으로 다시 쓴 학습 설명입니다. 원문 인용이나 서비스의 현재 기능 보장이 아닙니다.

처음 공부한다면 이렇게 시작하세요

  1. 준비: 만들 인물과 장면을 한 문장으로 정하고 참조 이미지 한 장을 준비합니다. 실습의 ‘준비’ 설명부터 읽으세요.
  2. 예시 확인: 어떤 얼굴·구도·빛을 유지할지 봅니다. 여기의 AI 그림은 학습용 예시이며 해당 툴의 실제 테스트 결과는 아닙니다.
  3. 입력: 실습의 프롬프트를 전체 복사하고 내 인물·장소·행동에 맞게 바꿉니다. 파일 첨부 순서와 선택한 모델·모드를 확인합니다.
  4. 확인: 이미지 또는 영상을 끝까지 봅니다. 얼굴, 손, 이동 방향, 대사와 호흡을 기준 이미지와 비교하세요.
  5. 수정: 문제 하나만 골라 다시 시도합니다. 바꾼 문장·설정과 결과를 기록해 같은 실수를 줄입니다.
