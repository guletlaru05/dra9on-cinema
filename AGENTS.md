# Tutorial example image policy

These instructions apply to future tutorial example images throughout this
repository. They record the owner's requested image workflow. They do not
authorize image generation for an unrelated website task.

- Generate tutorial example images through Higgsfield. Generate images only;
  never generate video for this workflow. Generate at most 6 images per tutorial,
  including comparisons and variants.
- Requested default model: GPT Image 2.5. For a useful comparison or a different
  style, choose Seedream 5.0 Pro or Nano Banana Pro according to the lesson. Before
  using a model, verify its current availability and exact name in Higgsfield;
  these requested names are preferences, not evidence of availability. Do not
  silently substitute an unavailable model.
- Before generating, tell the owner the selected model, image count, aspect
  ratios, and estimated total credits from current Higgsfield pricing. If the
  price cannot be verified, say so before starting. Follow the relevant
  Higgsfield generation and credit approval instructions.
- Use original, tutorial-specific subjects. Never use FALL 707 / 낙하 707
  characters, scenes, story settings, or references. Do not depict real people,
  recognizable works, brands, or logos. Keep a cinematic, dark visual mood that
  fits the site.
- Save each image's exact model name, aspect ratio, and complete submitted prompt.
  Display those same values in its prompt card without summarizing or rewriting
  the prompt. If generating a variant, retain its own generation record.
- Show the actual generated images to the owner before publishing them. Keep
  results unpublished until the owner has reviewed and approved them.
- Convert approved images to optimized WebP for the website, preserving legible
  instructional detail. Record output dimensions and file size. Put the model
  name and descriptive content keywords in each image's alt text, in the page's
  language. Do not add brands or logos to generated image content; ordinary
  adjacent site navigation is outside this image-content restriction.
- Do not retroactively regenerate existing illustrations unless the owner asks.
